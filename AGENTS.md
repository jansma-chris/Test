# Test website

## Assets

- Keep the website’s design references, images, and other source assets in the [Test Google Drive folder](https://drive.google.com/drive/folders/1SeNjW54kahYLoZ3yqxBkWxy1-3gvrcDo).
- Consult the design-system reference in Drive before changing the site’s visuals. Use Drive assets for local previews and keep private asset copies out of Git.
- To preview the current homepage, download the performance photo from Drive and save a local copy as `performance.jpg` next to `index.html`.

## Working files and versions

- Use [jansma-chris/Test on GitHub](https://github.com/jansma-chris/Test) for website source files and version history.
- Check for existing changes before editing, verify the page locally after editing, and commit each completed version with a descriptive message.
- Push the completed commit to GitHub and verify that it arrived. Use GitHub Desktop when the GitHub connection in chat cannot push.
